# Dallas RP — юридический помощник

Мобильное веб-приложение (PWA) для iPhone и настольных браузеров.

Исходники веб-приложения располагаются в `dallas-iphone/`. Сервис запускается командой `python dallas-iphone/server.py`.

**Важно:** каталог нормативных актов содержит предварительные карточки. Непроверенные сведения должны быть дополнительно сверены с официальной базой Majestic RP Dallas. Не размещайте в репозитории API-ключи.
